# 电影票务系统

## 技术栈

Spring Boot · MyBatis · MySQL · Redis（Redisson）· Kafka · Spring Security · MinIO

---

## 项目介绍

电影票务系统，C 端涵盖电影/影院浏览、选座购票等核心功能；B 端支持多影院后台管理。

---

## 职责描述

- **座位锁定**：基于 Redis Bitmap + Lua 脚本实现座位原子化检查与锁定，以极小内存开销支撑选座页高频查询，同时解决高并发场景下"一座多人"问题
- **超时关单**：基于 Redis ZSet + 轮询实现延迟队列替代 MQ 延迟队列，避免大量无效消息积压；通过数据库乐观锁解决支付与关单并发竞态问题，支付回调发现订单已取消自动触发退款补偿
- **认证方案**：用户端采用双 Token 实现无感刷新；管理端采用单 Token + Redis，限制单设备，支持即时吊销
- **缓存与限流**：针对热门电影高并发场景，采用逻辑过期 + 互斥锁异步重建缓存防御缓存击穿，布隆过滤器 + 缓存空值防御缓存穿透，TTL 抖动 + 缓存预热防御缓存雪崩；基于 Redis ZSet + Lua 脚本实现滑动窗口限流
- **异步解耦**：采用 Kafka 异步处理短信通知、票房统计等非核心流程；设计本地消息表 + 定时任务保证消息可靠性
